# Shared Notes

A private, real-time message board shared by a few accounts, hosted on **GitHub Pages only**: no backend and no database. The interface follows **Material Design 3** (five color themes, phone and desktop).

- **Accounts:** any number of accounts, all sharing one space. Sign in once per device and you stay signed in until you choose **Sign out** (avatar menu, top right).
- **Real time:** a message posted on one device appears instantly on every other signed-in device. Your messages sit on the right; other accounts' messages sit on the left with their account name.
- **Text, links, images, any file, voice:** messages are sent as plain text by default, exactly as typed, with clickable links. The **+** button opens **Photos & videos** (the phone's photo library) and **File** (the file picker). Images show inline (resized on the device first); other files download with their original name. Tap 🎤 for a voice message.
- **Text formatting (Word-style):** **+ → Text formatting** (or Cmd/Ctrl + Shift + X) shows a toolbar: bold, italic, underline, strikethrough, text size, text color, clear formatting, bulleted and numbered lists, indent, undo/redo and a larger editor. Styles apply directly in the message box as you type, and the message arrives looking the same.
- **Markdown and code:** **+ → Markdown & code** turns Markdown on: **bold**, _italic_, lists, quotes, tables, `inline code`, and fenced code blocks with syntax highlighting. Write ` ```python ` to name the language, or leave it out and it's detected automatically. Each block has a **Copy** button. Raw HTML is shown as text, and markdown images are not loaded. With Markdown off, `**` and ``` are sent as typed.
- **Pin:** pin one message for everyone. A bar under the top bar jumps to it. Pinning another message asks first, because the current one will be unpinned; deleting the pinned message removes the pin.
- **Themes:** the palette button offers dark blue (default), dark purple, black, white and paper. The choice is saved per device.
- **Safe deletes:** deleting a message or clearing all asks for confirmation first.
- **Nothing is stored:** messages live only in the memory of open devices. A device that opens later gets the current messages from devices already online. Once every device is closed, everything is gone.

## Accounts

See **[docs/accounts.md](docs/accounts.md)** for the full guide. In short:

```bash
npm install
npm run account:add       # first account (creates the space), or add another one
npm run account:change    # rename / change password
npm run account:delete    # delete an account
npm run account:list      # list account names
npm run account           # menu with everything
```

Each command offers to commit and push `src/account.js`; the site updates about a minute later.

## Auto-reply bot

`npm run bot` signs in with an account, waits for new messages and answers them with **Claude Code** or **Antigravity CLI** from that account. It can start a new conversation or continue an existing one, and the site link can be changed. See **[docs/bot.md](docs/bot.md)**.

```bash
npm run bot:setup         # first time: link, AI, new / existing conversation, options
npm run bot               # start (Ctrl+C to stop)
npm run bot:settings      # settings menu: change any single setting
npm run bot:url -- <link> # change the site link
```

## How it works

```
Device A ──┐  find each other via public Nostr relays (only an encrypted handshake passes through)
           ├──────────────────────────────────────────────────────────────
Device B ──┘  then talk directly with WebRTC (peer-to-peer, DTLS + an extra AES-GCM layer)
```

| Piece | What it does |
|---|---|
| `src/crypto.js` | PBKDF2-SHA256 (600 000 iterations) and HKDF helpers, AES-GCM seal/unseal, HMAC. |
| `src/accounts.js` | Multi-account format: one random **space key** for the whole space; each account stores a check value, the space key encrypted with that account's password, and its name encrypted with the space key. |
| `src/account.js` | The public account file generated by the CLI. It contains no password, and names are readable only by members. |
| `src/sync.js` | [Trystero](https://github.com/dmotz/trystero) room derived from the space key. Peers must pass an HMAC challenge, and every message is AES-GCM encrypted. |
| `src/main.js` | Sign-in, session (derived key in `localStorage`, never the password), chat feed, attachments, voice recording, pinning, themes, Material components (menus, dialog, snackbar). |
| `src/markdown.js` | Markdown → sanitized DOM: marked (GFM) + highlight.js (named or auto-detected language) + DOMPurify. |
| `src/rich.js` | Word-style formatting: turns the editor's content into a small set of allowed tags and classes, and re-sanitizes it on every receiving device. Also makes links clickable in plain text. |
| `tools/account.mjs` | The account CLI. |
| `bot/` | The auto-reply bot: drives the site in background Chrome, calls the AI CLI ([docs/bot.md](docs/bot.md)). |

Someone who only has the link sees the sign-in page and nothing else.

## Limits

- **At least one device must stay open** for messages to survive. That's the point, but don't use this to keep anything important.
- **Sizes:** up to 6 images and 10 files per message, files up to 25 MB in total, voice messages up to 5 minutes. Large files take a moment to reach each device, and every open device keeps them in memory.
- **Strict networks:** some mobile carriers and office networks block direct WebRTC connections. If devices keep showing "Waiting for other devices…", add a TURN server (`turnConfig` in `src/sync.js`; Cloudflare's free TURN works). That TURN server is the only server you'd ever need.
- **Phones in the background** drop the connection after a while (iOS especially); they reconnect and re-sync when you come back.
- **Voice:** needs microphone permission. Recordings use the browser's native format (WebM/Opus on Chrome and Android, MP4/AAC on Safari); current browsers play both.

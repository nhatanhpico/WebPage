# Shared Notes

A private, real-time note board shared across your signed-in devices, hosted on **GitHub Pages only**: no backend and no database.

- **One account**: sign in once per device; you stay signed in until you choose **Sign out**.
- **Real-time**: a note posted on one device appears instantly on every other device that has the page open.
- **Text, clickable links, images**: paste or drop images too. Images are resized and compressed on the device before sending.
- **Nothing is stored**: notes live only in the memory of open devices. A device that opens later gets the current notes from the devices already online. Once every device is closed, everything is gone.

## How it works

```
Device A ──┐  find each other via public Nostr relays (only an encrypted handshake passes through)
           ├──────────────────────────────────────────────────────────────
Device B ──┘  then talk directly with WebRTC (peer-to-peer, DTLS + an extra AES-GCM layer)
```

| Piece | What it does |
|---|---|
| `src/crypto.js` | PBKDF2-SHA256 (600 000 iterations) of `account + password` gives a master key; HKDF splits it into a room id, a signaling password, a handshake key and a message key. |
| `src/account.js` | Public **salt + check value** used to tell "wrong password" from "right password". It contains no password and is generated by `npm run account`. |
| `src/sync.js` | [Trystero](https://github.com/dmotz/trystero) room. Peers must prove they know the key (HMAC challenge) before they're let in, and every message is AES-GCM encrypted. |
| `src/main.js` | Sign-in, session (derived key in `localStorage`, never the password), feed, composer, image compression, links. |

Someone who only has the link sees the sign-in page and nothing else: without the password they can't find the room, connect, read or post.

## Manage the account

Run these in a terminal (Terminal / iTerm) inside this folder. Each command asks before writing anything, then offers to commit and push `src/account.js` for you.

| Command | What it does |
|---|---|
| `npm run account` | Menu with the options below |
| `npm run account:change` | Create the account, or change the account name and/or password. Asks for the current account + password first; press Enter to keep either one. |
| `npm run account:delete` | Delete the account. Asks for the current details and a "yes". After publishing, nobody can sign in and every device is signed out. |
| `npm run account:status` | Shows whether an account is set, when it last changed, and whether that change is published |

Options: `-- --force` skips the current-password check (if you forgot it), e.g. `npm run account:change -- --force`; `-- --no-push` only writes the file.

- Any change signs out every device, which then signs in with the new details.
- The account name and password are never stored, so nobody can read them back, including you.
- Use at least 10 characters. The check value in `src/account.js` is public, so a weak password could be guessed offline.
- GitHub Actions redeploys about a minute after the push.


## Limits

- **At least one device must stay open** for notes to survive. That's the point, but don't use this to keep anything important.
- **Strict networks**: some mobile carriers and office networks block direct WebRTC connections. If two devices keep showing "Waiting for other devices…", add a TURN server (`turnConfig` in `src/sync.js`; Cloudflare's free TURN works). That TURN server is the only server you'd ever need.
- **Phones in the background** drop the connection after a while (iOS especially); they reconnect and re-sync when you come back.
- Up to 6 images per note; HEIC images work in Safari, while other browsers may not decode them.

# Our little space 💕

A private, real-time note board for two (or more) of your devices, hosted on **GitHub Pages only**: no backend and no database.

- **One account**: log in once per device; you stay logged in until you press ⏻.
- **Real-time**: a note posted on one device appears instantly on every other device that has the page open.
- **Text, clickable links, photos**: paste or drop images too. Photos are resized and compressed on the device before sending.
- **Nothing is stored**: notes live only in the memory of open devices. A device that opens later gets the current notes from the devices already online. Once every device is closed, everything is gone.

## How it works

```
Device A ──┐  find each other via public Nostr relays (only an encrypted handshake passes through)
           ├──────────────────────────────────────────────────────────────
Device B ──┘  then talk directly with WebRTC (peer-to-peer, DTLS + an extra AES-GCM layer)
```

| Piece | What it does |
|---|---|
| `src/crypto.js` | PBKDF2-SHA256 (600 000 iterations) of `account + password` gives a master key; HKDF splits it into a room id, a signaling password, a handshake key and a message key. |
| `src/account.js` | Public **salt + check value** used to tell "wrong password" from "right password". It contains no password and is generated by `npm run account`. |
| `src/sync.js` | [Trystero](https://github.com/dmotz/trystero) room. Peers must prove they know the key (HMAC challenge) before they're let in, and every message is AES-GCM encrypted. |
| `src/main.js` | Login, session (derived key in `localStorage`, never the password), feed, composer, photo compression, links. |

Someone who only has the link sees the login card and nothing else: without the password they can't find the room, connect, read or post.

## Set up the account (once)

```bash
npm install
npm run account        # asks for Account + Password (at least 10 characters), writes src/account.js
git add src/account.js && git commit -m "Set account" && git push
```

GitHub Actions builds and deploys the site in about a minute. Run `npm run account` again to change the password; devices that were logged in with the old one are logged out.

> The check value in `src/account.js` is public, so a weak password could be guessed offline. Use a long one.

## Develop

```bash
npm run dev            # http://localhost:5173
npm run build          # → dist/
```

## Limits

- **At least one device must stay open** for notes to survive. That's the point, but don't use this to keep anything important.
- **Strict networks**: some mobile carriers and office networks block direct WebRTC connections. If two devices show "Looking for your other devices…" forever, add a TURN server (`turnConfig` in `src/sync.js`; Cloudflare's free TURN works). That TURN server is the only server you'd ever need.
- **Phones in the background** drop the connection after a while (iOS especially); they reconnect and re-sync when you come back.
- Up to 6 photos per note; HEIC photos work in Safari, while other browsers may not decode them.
